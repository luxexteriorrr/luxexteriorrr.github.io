# Sentra (Oracle™) — how to run it

Three-screen installation. RCA 2025 final show. **Runs on a local network, not the internet.**

## Start the server

```bash
cd ~/Desktop/luxexteriorrr.github.io/sentra
npm install        # only needed once
npm start
```

Server listens on port 3000, bound to `0.0.0.0` — so any device on the same wifi can reach it.

Find your machine's LAN address:

```bash
ipconfig getifaddr en0
```

## The three surfaces

Replace `<LAN-IP>` with the address from the command above.

| Screen | URL |
|---|---|
| Phone / chat | `http://<LAN-IP>:3000` |
| Billboard 1 | `http://<LAN-IP>:3000/billbord1/billbord1.html` |
| Billboard 2 | `http://<LAN-IP>:3000/billbord2/billbord2.html` |

All three must be on the **same wifi** as the laptop running the server. Socket.io relays
`conversation_fragments` from the chat to both billboards live; `new_user_started` resets them.

## ⚠️ The display is locked to iPhone 8 Plus

`chat.css` line 99 wraps lines 99–473 — the entire stylesheet — in a single media query:

```css
@media screen and (device-width:414px) and (device-height: 736px) {
```

`device-width` matches the **physical screen**, not the browser window, so resizing a desktop
browser will not trigger it. At any other size the page renders as unstyled Times on black.
That is not a bug and not a broken build — it is how it was written for the show.

To view or capture it correctly on a desktop: Chrome DevTools → device toolbar → iPhone 8 Plus.

## Requires an OpenAI key

`.env` (gitignored, never committed) holds:

```
OPENAI_API_KEY=...
```

`POST /oracle` forwards the conversation to OpenAI — model `gpt-4`, temperature 0.3, top_p 0.7,
max_tokens 200. If the call fails, the UI shows **"Sentra is silent"**. That message means the API
call failed — not that the app is broken.

## Why this can't go on GitHub Pages

Pages serves static files only. Three things need a running Node process:

- `/socket.io/socket.io.js` is generated by the socket.io server at runtime — it is not a file in
  this repo. On Pages it 404s, so `io` is undefined and `chat.js` line 18 throws, killing the
  whole script.
- `POST /oracle` — static hosts reject POST (405).
- The WebSocket relay between the phone and the billboards.

The OpenAI call also can't move into the browser: the API key would be readable in a public JS
file on a public domain.

Hosting it publicly would need a Node host (Render/Railway/Fly) **plus rate limiting**, or anyone
who finds the link can spend your OpenAI credit.
